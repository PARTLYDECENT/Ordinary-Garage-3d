# 3D Vehicle Garage

This is a 3D vehicle garage application built with Babylon.js.

## Features

*   View 3D vehicle models.
*   Navigate between different vehicle models.
*   Dynamic skybox with war-torn planet effects.
*   Toolbox for vehicle modifications.

## Toolbox Features

*   **Change Color:** Randomly changes the color of the current vehicle.
*   **Toggle Wireframe:** Toggles wireframe mode for the current vehicle.
*   **Reset Camera:** Resets the camera to its initial position and orientation.
*   **Toggle Ground:** Shows or hides the ground plane.
*   **Toggle Lights:** Toggles the main lights (Hemispheric and Directional) on/off.
*   **Toggle Auto Orbit:** Toggles automatic camera rotation around the vehicle.
*   **Shift + Pan:** Enables camera panning by holding Shift and dragging the mouse.
